# Hossein - DevOps engineer - website samples

Static portfolio website. No installation is required.

## Run locally
Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Add a project
Edit `assets/projects.js`, copy one project object, and change its values. Put screenshots in `images/`.

## Publish
Upload this folder to GitHub. It works directly with GitHub Pages, Netlify, Vercel, or any static host.

Update the placeholder GitHub, LinkedIn, and email links inside `index.html`.
